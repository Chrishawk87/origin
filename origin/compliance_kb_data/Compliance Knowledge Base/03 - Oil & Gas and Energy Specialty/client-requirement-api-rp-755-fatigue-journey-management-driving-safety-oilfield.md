# Journey Management / Driving Safety (Oilfield)

**Citation:** Client requirement / API RP 755 (fatigue)
**Category:** 03 - Oil & Gas and Energy Specialty
**Written program required:** Conditional
**Agencies commonly requiring (Y=commonly, C=client/scope-driven):** ISN: C, Avetta: C, Veriforce: C, PEC: C
**Related citations:** API RP 755

## Applicability / Trigger

Required by many operators for lease/field driving; addresses the leading cause of oilfield fatalities.

## Required Written-Program Elements

- Journey planning and route risk assessment
- Driver check-in / communication protocol
- Night-driving and remote-location limits
- Fatigue management (hours-awake limits; aligns to API RP 755)
- Vehicle standards, seatbelt policy, and in-vehicle monitoring where used

## Common Failure Points (why reviewers reject it)

- No journey planning/check-in process
- Fatigue limits absent
