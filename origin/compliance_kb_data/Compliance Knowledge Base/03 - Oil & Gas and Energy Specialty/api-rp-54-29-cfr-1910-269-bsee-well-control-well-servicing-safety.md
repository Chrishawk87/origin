# Well Control / Well Servicing Safety

**Citation:** API RP 54 / 29 CFR 1910.269 / BSEE
**Category:** 03 - Oil & Gas and Energy Specialty
**Written program required:** Conditional
**Agencies commonly requiring (Y=commonly, C=client/scope-driven):** ISN: C, Veriforce: C, PEC: C

## Applicability / Trigger

Required for drilling and well-servicing contractors.

## Required Written-Program Elements

- Well-control procedures and barrier philosophy
- Equipment inspection/testing (BOP, etc.)
- Personnel well-control certification (e.g., IADC WellSharp)
- Emergency response for kicks/blowouts
- Rig-up/rig-down safe work practices

## Common Failure Points (why reviewers reject it)

- Well-control certification not tracked
- BOP test records missing
