# DAFW / LTIR — Days Away From Work (Lost Time) Rate

**Citation:** 29 CFR 1904.7 / BLS SOII
**Category:** 07 - Safety Metrics & KPIs
**Written program required:** Reference
**Agencies commonly requiring (Y=commonly, C=client/scope-driven):** ISN: C, Avetta: C, Veriforce: C, PEC: C

## Applicability / Trigger

The narrowest severity rate: only cases with actual days away from work (lost-time), per 100 FTE. Sometimes labeled LTIR (Lost Time Incident Rate) or LTC rate. Excludes restricted-duty and transfer-only cases (which DART includes).

## Formula

DAFW/LTIR = ( Number of days-away cases × 200,000 ) ÷ Total hours worked

## Required Elements / Components

- Count of days-away cases (300 log column H)
- Total hours worked
- 200,000 base constant

## Benchmarks / Standards

BLS SOII 2024: all private industry DAFW ≈ 0.8–0.9. Reported on the 300A as the 'cases with days away from work' column.

## Common Failure Points (why reviewers reject it)

- Using DAFW and DART interchangeably
- Excluding cases that had days away AND restricted days (still a DAFW case)
