## Form 3 — Clearinghouse Query Log (49 CFR 382.701)

*Run a full pre-employment query before allowing a driver to operate a CMV (with the driver's electronic consent in the Clearinghouse). Run at least one query (limited or full) every 12 months for each current driver. Report actual-knowledge violations, refusals, and positive test results to the Clearinghouse as required.*

| Driver | Query type (pre-employ full / annual limited / annual full) | Date run | Driver consent on file | Result: prohibited status? | Action taken |
|---|---|---|---|---|---|
|  |  |  | ☐ | ☐ No  ☐ Yes | ______________ |
|  |  |  | ☐ | ☐ No  ☐ Yes | ______________ |

*A driver in "prohibited" status may not operate a CMV until they complete the return-to-duty process (SAP evaluation, education/treatment, negative RTD test). Since Nov 18, 2024, State licensing agencies also downgrade the CDL of a prohibited driver — a downgraded CDL reads as an automatic prequalification fail.*
