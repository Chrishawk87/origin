# ISNetworld / RAVS Review Process

**Citation:** ISNetworld (RAVS)
**Category:** 05 - Prequalification Agencies (Process)
**Written program required:** Reference
**Agencies commonly requiring (Y=commonly, C=client/scope-driven):** ISN: Y

## Applicability / Trigger

How ISN evaluates a contractor. Not a standard — the process your programs are graded against.

## Required Written-Program Elements

- RAVS (Review & Verification Services) reviews each written program against the OSHA/DOT standard + the hiring client's requirements
- Each program uploaded separately and graded A / B / F, typically within ~14 days
- Company-specific content required (name, administrator, real scope)
- OSHA 300/300A logs, TRIR/DART/EMR, and insurance (COI) also reviewed
- RAVS 360 (formerly RAVS Plus) verifies field implementation
- Revalidation approximately every 3 years or on standard changes

## Common Failure Points (why reviewers reject it)

- Submitting a generic template with placeholders
- Bundling multiple programs into one upload
- Wrong or missing CFR citation
- Scope mismatch with the contractor's actual work
