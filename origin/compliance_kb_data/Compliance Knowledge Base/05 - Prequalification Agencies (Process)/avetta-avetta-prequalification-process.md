# Avetta Prequalification Process

**Citation:** Avetta
**Category:** 05 - Prequalification Agencies (Process)
**Written program required:** Reference
**Agencies commonly requiring (Y=commonly, C=client/scope-driven):** Avetta: Y

## Applicability / Trigger

How Avetta evaluates a contractor.

## Required Written-Program Elements

- PQF (Pre-Qualification Form) questionnaire plus document upload
- Written safety programs reviewed against the client's configuration
- Insurance (COI), EMR, OSHA 300/300A, and TRIR/DART/LTR metrics
- No universal 'Avetta certification' — requirements vary by connecting client

## Common Failure Points (why reviewers reject it)

- Assuming one Avetta profile satisfies all clients
- Metrics inconsistent with the OSHA logs
