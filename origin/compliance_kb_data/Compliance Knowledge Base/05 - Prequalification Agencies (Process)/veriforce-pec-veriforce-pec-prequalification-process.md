# Veriforce / PEC Prequalification Process

**Citation:** Veriforce / PEC
**Category:** 05 - Prequalification Agencies (Process)
**Written program required:** Reference
**Agencies commonly requiring (Y=commonly, C=client/scope-driven):** Veriforce: Y, PEC: Y

## Applicability / Trigger

How Veriforce (which merged with PEC Safety) evaluates a contractor. Strong DOT/pipeline focus.

## Required Written-Program Elements

- Written programs reviewed plus heavy operator-qualification and training-record verification
- Operator Qualification under 49 CFR 192/195
- Drug & alcohol testing program (Part 382 / Part 40)
- PEC Core / SafeLandUSA / SafeGulf training often bundled
- Insurance and incident metrics

## Common Failure Points (why reviewers reject it)

- OQ tasks not mapped
- Training records (PEC Core/SafeLand) not current
