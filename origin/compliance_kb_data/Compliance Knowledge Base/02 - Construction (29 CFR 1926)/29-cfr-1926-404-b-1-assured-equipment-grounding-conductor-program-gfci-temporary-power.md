# Assured Equipment Grounding Conductor Program / GFCI (Temporary Power)

**Citation:** 29 CFR 1926.404(b)(1)
**Category:** 02 - Construction (29 CFR 1926)
**Written program required:** Conditional
**Agencies commonly requiring (Y=commonly, C=client/scope-driven):** ISN: C, Avetta: C, Veriforce: C

## Applicability / Trigger

Applies to temporary wiring on construction sites. Employer must use EITHER GFCI protection OR a written Assured Equipment Grounding Conductor Program (AEGCP).

## Required Written-Program Elements

- Written description of the AEGCP (if GFCI is not used for all receptacles)
- A competent person to implement the program
- Continuity and terminal-connection tests of equipment grounding conductors before first use, after repair, after damage, and at least every 3 months
- Color-coded/documented test records for cords and tools
- OR: GFCI protection on all 120V, single-phase, 15/20/30A receptacles

## Training

Train the competent person on the required tests and record system.

## Common Failure Points (why reviewers reject it)

- Neither GFCI nor a written AEGCP clearly chosen
- No documented grounding-conductor tests
- No competent person named
