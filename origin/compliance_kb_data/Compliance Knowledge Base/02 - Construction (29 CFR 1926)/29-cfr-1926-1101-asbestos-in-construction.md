# Asbestos in Construction

**Citation:** 29 CFR 1926.1101
**Category:** 02 - Construction (29 CFR 1926)
**Written program required:** Conditional
**Agencies commonly requiring (Y=commonly, C=client/scope-driven):** ISN: C, Avetta: C

## Applicability / Trigger



## Required Written-Program Elements

- Written compliance program for Class I-IV asbestos work as applicable
- Exposure assessment/monitoring; negative exposure assessment where claimed
- Regulated areas, engineering controls, and work-practice controls by class
- Respiratory protection and hygiene facilities/decontamination
- Medical surveillance and training (by class)

## Training

Class-specific training; competent person on-site for Class I-II.

## Common Failure Points (why reviewers reject it)

- No class-specific written program
- Negative exposure assessment undocumented
- Competent person absent
