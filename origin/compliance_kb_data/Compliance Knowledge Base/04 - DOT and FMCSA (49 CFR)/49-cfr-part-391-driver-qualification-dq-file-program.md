# Driver Qualification (DQ File Program)

**Citation:** 49 CFR Part 391
**Category:** 04 - DOT and FMCSA (49 CFR)
**Written program required:** Yes
**Agencies commonly requiring (Y=commonly, C=client/scope-driven):** ISN: C, Avetta: C, Veriforce: Y, PEC: C

## Applicability / Trigger

Applies to motor carriers. Governs how drivers are qualified and what the DQ file must contain.

## Required Written-Program Elements

- Written procedure for qualifying drivers
- DQ file contents: employment application, MVR (annual review), road test/CDL equivalency, medical examiner's certificate, Clearinghouse queries, annual violation certification, list of violations
- Medical certification tracking
- Disqualification criteria and process

## Recordkeeping & Retention

Retain DQ file for duration of employment + 3 years.

## Common Failure Points (why reviewers reject it)

- Generic 'driver safety' policy instead of a Part 391 DQ program
- Annual MVR review not documented
- Medical cert tracking absent
