# Hazardous Materials Transportation Security Plan

**Citation:** 49 CFR Part 172 Subpart I (172.800-.804)
**Category:** 04 - DOT and FMCSA (49 CFR)
**Written program required:** Conditional
**Agencies commonly requiring (Y=commonly, C=client/scope-driven):** ISN: C, Avetta: C, Veriforce: C, PEC: C
**Related citations:** 49 CFR 172.704 (hazmat training)

## Applicability / Trigger

Applies to shippers/carriers of placarded/certain hazardous materials.

## Required Written-Program Elements

- Written security plan addressing personnel security, unauthorized-access, and en-route security
- Risk assessment of the hazmat operations
- Employee security awareness and in-depth security training
- Plan review/update at least annually

## Common Failure Points (why reviewers reject it)

- No annual review of the security plan
- Security training not documented
